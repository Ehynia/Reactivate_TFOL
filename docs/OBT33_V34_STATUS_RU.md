# OBT33 v34 — проверенный PvE result gate и исследование AI

Основа: OBT33 v33. Полная тестовая сборка в разговоре, но **не** опубликована в GitHub Releases. В публичном репозитории размещаются только текстовый патч и описание, НЕ оригинальный UE4 EXE/PAK.

## P0: PvE результат
Проверен реальный дефект `Release/Server/game_protocol.py`: `TutorialBattleReq(176)` допускал последующий OB15 только при `Mode=='TDM'`. PvE отклонялся нулевой наградой. В патче `patches/V34_PVE_RESULT_GATE.patch` разрешена только ветка `Mode=PVE/PVEDEFEND`, если ранее серверным контекстом подтверждены `mode=3001`, `state=travel_dispatched` и `round_id`. Подтверждённый раунд может получить ограниченный расходник за участие до потери post-match состояния. Победные валюты/XP НЕ выдаются без проверенного native `OB15`, ограничения экономики остаются.

## Боты
Исходная `AIStrenthTable.bytes` содержит 32 строки формата `<I5f>`; что означают 5 float-полей пока не доказано. Поэтому исходный ресурс не патчился. В ZIP включены `Release/Server/bot_aim34.py`, `ai_profile_audit34.py` и их тесты: расчёт упреждения движущейся цели, LOS/friendly проверка, реакция по сложности и ограниченный поворот. **Это не подключено к UE4 AIController; работающий аим в игре не заявляется.** Понадобится восстановить реальный ABI AIController и трассировку прицела на listen-хосте.

## Проверки
17 новых тестов и 29 целевых прошли. Широкий набор: 124/127 PASS, 2 FAIL и 1 ERROR — тесты требуют старой схемы SQLite v10 и более раннего перехода с таймера. Независимый исходный v33 подтвердил ошибки SQLite и раннего таймера, а также неизменность кода из третьего теста. Отдельной Windows UE4-проверки ещё нет.

## Неисправленные блокеры
`OnBattleResultDataTimeout`: нет проверенной доставки native `GameStopInfo+AccBattleInfo` и окна результата; PvE core HP/waves/timer на listen-хосте всё ещё не восстановлены; настоящая мультиплеерная миграция хоста не подтверждена.

План: сначала зафиксировать EndMatch -> OB15 -> UI/results -> economy на Windows, затем миссионные AI/таймер/урон ядра, потом aim/CTF/2-PC тесты.
