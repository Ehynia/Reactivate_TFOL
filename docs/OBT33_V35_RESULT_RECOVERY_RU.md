# OBT33 v35 — попытка восстановления штатного окна результатов

Основа: OBT33 v34, оригинальные EXE/PAK не изменены. Пакет OBT33 v35 создан для локального Windows-теста, **НЕ является опубликованным GitHub Release**.

## Новый подтверждённый разрыв
2016 OBT schema / constants определяют `MSG_SYNC_BATTLE_INFO = 60`, внутри `RoomSeq`, `GameStopInfo`, `AccBattleInfo[1..16]` и необязательные наградные списки. Ранний сервер не отправлял этот пакет вообще: только `TutorialBattleRes(177)`, `SyncItemData(39)`, `SyncPlayerInfo(62)` и `JijiaBattleInfoRes(116)`. В Windows-отчёте наблюдается `WaitingPostMatch` затем `OnBattleResultDataTimeout` (примерно через 6 секунд).

## Исправления v35
1. `postmatch_wire35.py` формирует и проверяет подлинную TDR-структуру `SyncBattleInfo(60)` **из полученного native OB15**, не из предположений о счёте.
2. `battle_statistics.handle_snapshot` отправляет команду 60 первой; затем 177/кошелёк/профиль, сохраняет `RoomSeq` и защиту от повторного начисления.
3. Если оригинальный клиент не прислал 176, обработчик может принять `TF15 kind=7` с подтверждённым, достаточно длинным **локальным** раундом: режим/ID комнаты, ack travel, запись `round_attempts`, не менее 45 секунд. Replay ID детерминирован, запись результата и валюты атомарна.
4. Публичный VPS не использует этот обход: локальный bridge kind7 **не является криптографическим доказательством результата**. Это совместимость для локального теста, не античит.
5. В тестовом полном ZIP лежат `V35_SERVER_PATCH.diff`, 7 новых тестов и `V35_RESULT_RECOVERY_PROOF.json`.

## Проверки
35 целевых PASS. Более широкий набор 96: 94 PASS; две старые проверки ожидают прежнее 5-секундное начало вместо текущего 30-секундного выбора героя. ZIP CRC проверен, EXE и лаунчер равны v34 побайтово.

**Нерешённая часть:** по реальным логам сам клиент НЕ отправляет `OB15` вообще. Чтобы реанимировать UI на настоящем Windows, нужно безопасно перехватить `EndMatch`/статистику игрового UE4 Listen Server (авторитетные `GameStopInfo` + `AccBattleInfo`), передать через `TF15 kind=7` ДО тайм-аута и проверить обработку пакета 60 клиентом. Предварительный серверный тест ещё не доказывает, что окно откроется.
