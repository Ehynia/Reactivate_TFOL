# OBT33 v40 — Megatron tutorial / PvE Listen Server experimental mini-patch

**Основа:** текущая OBT33 v38 с установленным v39 Reddit News. **Это мини-патч 45 256 байт, а не полная сборка и не GitHub Release.** Экспериментальный EXE / PAK / базы игроков не публикуются в GitHub.

## Исправлено непосредственно

В `tutorial_mission36.py` запрос оригинальной тренировки `OB27` передаёт **Оптимуса Прайма (hero=15)** независимо от выбранного в гараже героя. Это отдельный приватный уровень с Мегатроном (`map=1009,action=2,mode=1004,bots=0`). ID 15 проверяется по собственности игрока. Логин, nickname_set и SelectedCharacter не меняются. Обучение не отмечается завершённым лишь по факту перехода на карту.

Исходники GitHub: [server/tutorial_mission36.py](../server/tutorial_mission36.py).

## Эксперимент PvE (отдельное явное включение)

Исследованы хуки x86 OBT 4.14.3 из переданного пользователем старого v26.2. Пять точек в v38/v39 проверены по исходным байтам:

- `0x80a9f0` — запись данных о волне и отправка OnRep
- `0x80aa20` — конец волны и OnRep
- `0x807ef0` — **сохранён полноценный оригинальный** `AUTPVEDefendGameMode::HandleMatchHasStarted` через trampoline, после него запрашивается синхронизация башен; опасный общий обход v26.2 не применяется
- `0x807a50` — периодическая отправка текущего состояния HP башен, при активном listen-хосте PvE (без выдуманного урона)
- `0x5ecea6` — экспериментальная ветка нотификации игрового таймера `RemainingTime`

В исходной сборке хуки **выключены**. Опциональная экспериментальная установка через `install_v40.py --apply` в корне локального архива проверяет **полные SHA-256 EXE и манифеста**, накладывает 20 211-байтную бинарную дельту и создаёт две резервные копии. `--restore` откатывает обе. Исходная игра не распространяется, пользовательские базы и PAK не трогаются.

## Проверки

- Обычная повторная сборка `build_test.py` с выключенным флагом: **побайтово совпадает** с оригиналом OBT33 v39.
- С флагом `TFOL_ENABLE_PVE_NATIVE_EXPERIMENT=1`: собран отдельный PE; подтверждены пять статических точек по x86-сигнатурам, логика оригинального trampolining визуально сверена в disassembler.
- **88/88** целевых Python-серверных тестов и **4/4** теста установки, отказа на чужом EXE и отката: PASS.
- Один старый тест ожидает ранний старт матча до окончания 30-секундного выбора героя и намеренно не учитывается как корректное поведение v38.
- **НЕ проверены**: реальная Windows UE4-сессия, удар инсектикона по ядру, его урон, реальный PvE-таймер, активация босса, завершение тренировки, окно выбора имени **после** босса.

Не выдавать обновление клиентского OnRep за реализацию игрового урона/AI. Следующий приоритет: доказать потоки реального UE4 GameMode/PVE Tower и подтверждение завершения обучения, затем native OB15 -> UI results -> XP/currency.

Инструкции установки и исходные diff доступны внутри локального mini ZIP. Оригинальные Tencent/TFOL EXE и PAK в публичный репозиторий не загружены.
