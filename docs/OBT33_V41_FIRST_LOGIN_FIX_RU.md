# OBT33 v41 — штатное одноразовое обучение без интерфейса лобби

Полная тестовая сборка: Reactivate_TFOL_OBT33_v41_ORIGINAL_FIRST_LOGIN_FULL.zip, 102257229 байт, SHA-256 c91fe3ee852ae1b5ff9b16f0a5a67a90eec245a0ccce754d53322b2cb9d09069. Исходный EXE и PAK не опубликованы в GitHub.

## Ошибка
v36–v40 отправляли LoginDataRes(Result=ok) и меню лобби, а затем спустя 8 секунд запускали карту Tutorial_Scene отдельной командой OB27. Из-за этого подсказки обучения работали, но внизу экрана оставалась панель Новости/Гайды/Задания/Почта. Первая миссия — обязательное первоначальное обучение перед выбором ника, не тренировочный матч.

## v41
- Для нового зарегистрированного аккаунта с tutorial_required=1, nickname_set=0 и непройденным обучением LoginDataRes(4) содержит Result=badName и пустое PlayerInfo.Name. По исследованной ветке оригинального обработчика OnMSG_LOGIN_DATA_RES это инициирует StartTutorialLevel до создания интерфейса лобби.
- Отключён отложенный OB27 для обучения с Мегатроном; обычные матчи и PvE не переводятся на новую логику.
- Первичные UI-пакеты лобби, новостей, почты и режимов не отправляются во время одноразового обучения, heartbeat не добавляет ленту новостей.
- При подтверждении первого выбранного ника через CreateRoleDataReq(5) возвращаются CreateRoleDataRes(6), SyncPlayerInfo(62) и начальные данные лобби.
- При повторном входе с nickname_set=1 не запускается обучение; логин, пароль и существующая SQLite не меняются.
- Команда выбора ника не подделывает победу над Мегатроном и не записывает tutorial_completed_at без проверенного события UE4.

## Проверка
79 из 79 целевых тестов прошли. ZIP содержит 673 файла, CRC проверен. Launcher и игровой EXE побайтово совпадают с v38. Отдельно нужно испытать Windows UI, бой с боссом и диалог ника после победы: это пока НЕ подтверждено.
