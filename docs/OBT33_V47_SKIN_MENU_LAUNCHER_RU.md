# OBT33 v47 — исправление выбора скинов и запуска локализации в Windows

**База:** OBT33 v46. Пользователь предоставил два скриншота: оригинальная игра показывает `未知错误` при переключении скина, а лаунчер пытается выполнить путь `...\Release\` как shell-команду и выдает ошибку cmd.exe. Это тестовый патч, **не** опубликованный GitHub Release, и Windows UI не тестировался непосредственно.

## Проверенные изменения

1. В обеих копиях WinForms исходника `ReactivateStandalone.cs` команда `translations --launcher-root` больше не запускается через `cmd.exe /k`. Теперь используется `ProcessStartInfo.FileName = python.exe`, отдельные quoted-аргументы и `UseShellExecute=false`. Это не интерпретирует имена папок с кириллицей и пробелами как shell-команды.
2. Убрана оставшаяся после v42 обязательная предварительная полная обработка автоперевода: в `LaunchRequest` теперь `TranslationMode=null`. Backend `launcher_entry.py` при этом использует существующую ручную RU/EN установку (`translation_budget=0`) без сетевых провайдеров и без прогресс-блокировки на 1%. Установленные готовые языковые файлы сохраняются.
3. Обновлён кеш скомпилированного WinForms с `Reactivate.UI.v42.exe` на `Reactivate.UI.v47.exe` в исходнике собственного bootstrap и **только в двух UTF-16LE строках одинаковой длины** файла `Release/Reactivate.exe`. Оригинальный `TFOL_OBT.exe` и игровые PAK не менялись.
4. `EquipItemReq(40)` для скинов принимает только принадлежащие игроку реальные ItemData.Id, исходные ID косметического ресурса или ID предложения в магазине, проверяет базовую модель и однозначный предмет-держатель. Смена оружейного скина может выполняться через персонажа, у которого действительно экипировано соответствующее оружие.
5. После выбора отправляются `EquipItemRes(41)`, обновлённый предмет `SyncItemData(39)` и содержимое косметической сумки `SyncBagData(38)`. Снятие активного скина через `UnEquipItemReq(287)` также поддерживается независимо от снятия обычного оружия.
6. Никакие некупленные скины не выдаются, цена и кошелёк не подменяются; ошибки владения и несовместимые базы отклоняются.

## Честные ограничения

**Не утверждаем, что сообщение `未知错误` исчезло у пользователя:** скриншот не содержит конкретного запроса. Ранее тесты посылали только заведомо правильный внутренний ID, а реальный клиент может присылать иную форму. V47 охватывает дополнительные проверяемые варианты, но нужен повторный тест Windows. Если ошибка остается, включить отчеты только в настройках лаунчера и прислать короткий лог с сетевым `EquipItemReq`/`UnEquipItemReq` без учетных данных.

Окно результатов боя и настоящий native OB15 по-прежнему не восстановлены этим патчем.

## Установка

Полный v47 распаковать отдельно и выбрать прежнюю установленную оригинальную игру. Мини-патч накладывать **только** поверх полного v46 после закрытия лаунчера и сервера, с резервной копией каталога. Данные SQLite и исходные игровые ресурсы патч не меняет.
