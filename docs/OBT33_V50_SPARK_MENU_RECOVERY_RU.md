# OBT33 v50 — Spark-меню: серверные слоты, предметы и схемы

Оригинальный OBT33 v49 при LoginDataRes(4) передавал `Count=0,GridIdList=[]`, хотя `SparkGridTable.bytes` содержит 30 оригинальных ячеек, а сервер уже сохранял две бесплатные схемы (`SparkSchemePriceTable.bytes`). Это подтверждённая серверная причина возможной блокировки раздела «Искры». Отдельная нативная блокировка UMG пока не проверена.

## Исправления

- Восстановлен список открытых ячеек `LoginDataRes.GridIdList`: стартовые оригинальные ID 1,10,19 плюс открывающиеся по уровню и купленные. `Count` точно равен числу записей.
- 3 оригинальных стартовых предмета `ItemSparkTable.bytes`: 20101, 20201, 20301. У каждого игрока по одной Искре в сумке №3, повторная выдача запрещена. Данные сохраняются в отдельной `obt_spark_items`, SQLite schema number остаётся 11.
- Добавлены оригинальные 161/162 и 163/164 для покупки схем и ячеек. Две стартовые схемы бесплатны, списание за покупку атомарно и идемпотентно. Для ячеек использована проектная цена в серебре по последнему числу в оригинальной таблице; достоверная историческая валюта для этой операции не доказана.
- В `SparkConfigReq(137)` добавлена проверка, что ячейка открыта, Искра из оригинальной таблицы действительно принадлежит пользователю и её цвет соответствует оригинальному типу слота. Подделка, чужой инвентарь и закрытые ячейки отклоняются.
- `SyncSparkConfigReq(139)`, `SelectSparkConfigReq(141)` и `QueryJijiaSparkReq(245)` поддерживают сохранение схем.
- Запрос лотереи 147 получает корректную структуру, но сам розыгрыш 149 возвращает «unavailable». Выдача призов не реализована и не подделывается.

## Проверки и ограничения

43 актуальных регрессионных теста PASS, включая один реальный loopback TCP-сервер: вход, открытые ячейки, предмет, установка и покупка. Старый тест v37, требующий два пакета после смены скина, падает и на исходной v49 — актуальная v47+ намеренно передаёт третий `SyncBagData(38)`.

Windows UI не тестировался, поэтому нет гарантий, что кнопка раздела «Искры» станет активной: UE4 может дополнительно проверять локальный unlock/level flag. Лотерея, разбор и крафт Искр, специальные модульные эффекты остаются незавершёнными. Исходные EXE и RU/EN PAK побайтово совпадают с v49. Реальные пользовательские SQLite не поставляются и не изменяются при распаковке.
